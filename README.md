# Super Spanish — Realidades 2A · Misión memoria

Unidad educativa interactiva **sin backend** (HTML, CSS y JavaScript puro) preparada para GitHub Pages.

## Temas
- Vocabulario de rutinas, higiene, ropa y objetos personales
- Eventos, emociones y expresiones
- Verbos reflexivos, pronombres, conjugación, partes del cuerpo y posición de pronombres
- Ser y estar: conjugación y usos
- Posesivos cortos y largos y posesión con «de»

## Actividades
Explicaciones bilingües, tarjetas de memoria, mega quiz aleatorio (10/20/30 preguntas), rellenar espacios, parejas, memoria visual, ordenar oraciones, comprensión auditiva mediante voz del navegador, reto final y seguimiento del progreso.

## Publicar
1. Crea un repositorio nuevo (o usa uno existente).
2. Sube `index.html` a la raíz de la rama principal.
3. En **Settings → Pages**, elige **Deploy from a branch**, rama `main`, carpeta `/ (root)`.
4. Abre el enlace de GitHub Pages que aparecerá en la configuración.

## Notas
- Se puede abrir `index.html` localmente sin servidor.
- El progreso se guarda en `localStorage` del navegador, no se envía a ningún servidor.
- La función «Guardar progreso en PDF» abre el diálogo de impresión, donde se selecciona «Guardar como PDF».
- La pronunciación usa las voces disponibles en el dispositivo (Web Speech API), por lo que la calidad y disponibilidad pueden variar.
- Fuente Fredoka cargada desde Google Fonts cuando hay internet; sin conexión funciona la fuente alternativa del sistema.
- El vocabulario y los ejemplos son material didáctico original de repaso, no una reproducción íntegra del libro.
